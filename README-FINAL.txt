Flip Rush 7 Android v1.4.0 (versionCode 5)

Purpose of this wrapper update:
- Preserves the same Flip Rush 7 live website and package ID.
- Keeps microphone permission support for WebRTC voice chat.
- Forces Android communication audio to the built-in speaker after voice permission is granted, with a fallback to speakerphone routing on older Android versions.
- Uses the same permanent signing secrets as prior signed releases.

Do not create a new signing key. Build with FINAL-RELEASE-WORKFLOW.yml.
