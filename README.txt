Flip Rush 7 - Flat Android Wrapper

This Android project is intentionally flat. There is NO app folder.
Upload these files directly to the root of the GitHub repository:

AndroidManifest.xml
MainActivity.java
build.gradle
gradle.properties
settings.gradle

Do not upload WORKFLOW-PASTE-INTO-GITHUB-ACTIONS.yml as the Android project workflow location.
Instead, open GitHub > Actions > set up a workflow yourself, and paste its contents there.

The app is preconfigured to load:
https://flip-rush-7-60k8.onrender.com/

The GitHub Action produces:
build/outputs/apk/debug/app-debug.apk
